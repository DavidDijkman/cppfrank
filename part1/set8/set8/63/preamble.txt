We are asked to create a wrapper class around the unrestricted
union "Data" from exercise 62. This wrapper class holds information
on the type of Data, which Data itself does not know.

Even though the exercise disallowed it, we have made a small change to
main.cc. The array of doubles is now allocated using new to allow its 
ownership to be handed over to the Wrap/Data class. We considered the 
alternative of having the Data class copy the contents of the array, but 
this couldn't be done cleanly without also passing the array size to the
constructor. Alternatively, we could've kept the double array allocated on 
the stack, but it felt unintuitive not to have the Data class be in charge of
de-allocating its own memory.

You can initialize a VALUE of '0' with any expression that can only be
interpreted as a size_t and not one of the other types.
- Wrap{ false }
- Wrap{ 1 - 1 }
- size_t val = 0; Wrap{ val }
