We are asked to adjust the Strings class, such that when memory is allocated, 
data is either copied or moved based on the input given. We add a member 
iterate, the repeatedly calls add(), such that we can measure the time
difference between copying and moving data. 

When we use time with the given main script, we get the following outcome:

When copying data:
time ./main 10000
First: SHELL=/bin/bash
Last:  _=./main

real    0m0.829s
user    0m0.771s
sys     0m0.016s

When moving data:
time ./main 10000 move
First: SHELL=/bin/bash
Last:  _=./main

real    0m0.689s
user    0m0.645s
sys     0m0.011s

Therefore, we find that moving data is faster.
