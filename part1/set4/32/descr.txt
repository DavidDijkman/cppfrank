We need to examine compilation time differences by using different ways of
constructing the program. We will do a plain compilation, and different 
variations of precompiled headers. 

We will be timing the compilation time using time icmbuild. 
In between each compilation, we use icmbuild clean to have a clean start

- Plain compilation of the program
We get the following result:
real    4m14.880s
user    3m9.242s
sys     0m19.841s


- Compilation of the program using precompiled headers

- Remove compilation results of previous compile and redo compilation:
real    0m13.157s

- Conclusions
Before writing our conclusions, a short note about the differences between 
real, user and sys: real is the computation time before finishing. user is the
 computation time taken by CPUs. sys is time spent in Kernel space. In case of
  single-threading, real is approximately equal to the sums of user and sys. 

First, we observe that plain compilation is faster than compilation using 
precompiled header files. The compilation using precompiled header files takes
a similar amount of time as using an SPCH. The storage of using multiple 
precompiled header files is much larger than a single SPCH. Precompiled 
headers reduce CPU time, but introduce heavey IO bottlenecks due to writing
of large .gch files. Multithreading reduces compilation time significantly,
and when using ccache G++ the compilation time can be significantly reduced
again.
