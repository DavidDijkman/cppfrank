Exercise 2 asks us to answer 5 questions about some basic C++ concepts.

1. We must describe the difference between a declaration and a definition in c++. 
A declaration 'declares' that a function, method, class, or variable 
exists, and in the case of a method or function what it returns, and what 
arguments it takes. A definition describes what the content of the declared 
function/method/class/variable.

2. We must describe what header files are used for.
A header file describes the interface of a source file. It holds the 
declarations of what is contained in the connected source file. These header 
files can then be included in other source files to make use of these 
declarations.

3. We must describe in what part of program construction the compiler uses header files and libraries.
Header files are used first, during pre-processing, the declarations in the 
header file necessary to compile code that uses these declarations. It does 
however, not need the definitions yet. These are contained in the library and 
are necessary during linking, which is performed by the linker after 
compilation.

4. Is a library an object module?
A library is not exactly an object module. A library is
an archive of object files. When linking, the linker adds only the object 
files from the library that are necessary for running the program to the 
executable.

5. We must describe why an object file containing int main() is not executable.
This is because this object file does not contain the definitions for any of 
the functions that may be used in main() the program first has to be linked to
ensure that all necessary definitions are included. In theory, an object file 
for a main() function which doesn't include any header files contains all 
information necessary to run the program, but in this case an object file 
simply isn't structured to be executable.
