Description of object and executable files

an executable file is a self-contained set of machine code that can be 
understood and executed by a computer.

an object file contains compiled code together with metadata that describes 
how to link the object file to other modules. It is usually not directly 
executable, and a linker is used to combine the object file with other modules 
to create an executable.
