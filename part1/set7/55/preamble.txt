We are asked to make a class named Lock, that prevents clobbering of updates 
on a program made by two different users. Constructors of Lock write a lock 
file which is used for lock-administration. Locking goes through the function
flock() while unlocking goes through close(). 

A library is made which contains the class elements. This is done by adjusting
our makefile program, which looks like this:

CXXFLAGS = -std=c++20 -Wall -Werror

OBJECTS = lock/lock1.o \
          lock/lock2.o \
          lock/lock3.o \
          lock/lockpath.o \
          lock/open.o \
          lock/stringname.o

libcfbutility.a: $(OBJECTS)
	ar rcs libcfbutility.a $(OBJECTS)

$(OBJECTS): lock/lock.h lock/lock.ih

clean:
	rm -f $(OBJECTS) libcfbutility.a

Here, ar rcs libcfbutility.a $(OBJECTS) builds the library by inserting all 
object files to the archive.
It creates libcfbutitility.a inside the folder of the exercise, while the
program using the library can be placed in another folder. This folder is 
named program in our case.
