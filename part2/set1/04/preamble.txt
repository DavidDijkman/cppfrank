The error occurs because getline(in, str) does not return a bool but returns
the stream itself. The compiler cannot convert an istream into a bool, because
of how the conversion operator is defined. As seen in the error, the 
conversion operator is declared explicit, while return ... is an implicit
conversion.

We are asked to change promptGet's body so that the code does compile.
We can do that using static_cast<bool>. 

We are also asked to make the code compile, by leaving promptGets body as it 
is.
